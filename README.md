# Mi Entreno

App para crear rutinas de ejercicio, apuntar entrenamientos y ver tu historial.
Funciona en el móvil y en el ordenador, y se puede instalar como una app.

## Qué hace
- **Rutinas:** crea rutinas con sus ejercicios, series, repeticiones y peso.
- **Entrenar:** empieza una rutina (o un entreno libre), marca cada serie y usa el temporizador de descanso. Te recuerda el peso de la última vez.
- **Historial:** consulta cada entreno con su duración, sus series y los kilos movidos.

Los datos se guardan en el propio dispositivo.

## Probarla en el ordenador
```bash
python3 -m http.server 5173
```
Después abre http://localhost:5173

## Instalarla en el móvil
Primero hay que publicarla en internet (por ejemplo, con GitHub Pages). Después, ábrela en el móvil:
- **iPhone (Safari):** botón Compartir → «Añadir a pantalla de inicio».
- **Android (Chrome):** menú ⋮ → «Instalar app».
